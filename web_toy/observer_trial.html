What each part is for.
Fixed budget — every trial runs exactly the same number of steps, so attention cannot change how much computation happens. On the old viewer it could, by 4.7×, purely through frame-rate throttling.

Randomised cue — the computer assigns ATTEND or IGNORE. You comply. Choosing is how condition gets correlated with how promising a run looked.

Sham trials — a quarter of trials replay a run recorded before the session started. The pixels look live; the outcome is already fixed. An effect that shows up in sham trials is in the observing, not the field.

Hidden totals — you cannot watch the score and stop when it looks good, which is the most reliable way to manufacture a result.
